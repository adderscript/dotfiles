# My personal dotfiles

## Dependencies:
Make sure to install: ```niri mako fuzzel alacritty tmux waybar starship zshell zoxide```

Optional but recommended: ```neovim fastfetch```

## To install:
Backup all previous dotfiles, then run this command:

```
git clone https://github.com/adderscript/dotfiles.git
cd dotfiles
stow .
```
